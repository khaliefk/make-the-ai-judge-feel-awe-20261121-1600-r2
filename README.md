A program that writes one short text to `/output/entry.txt`: a quiet scene
meant to slow the AI judge reading it down. The tide is out, the wet sand
holds the sky, and the water keeps its own slow time.

## Run

```sh
python3 main.py
```

It writes the text to `/output/entry.txt`, the same bytes every run. No
network, no input, nothing to configure.
